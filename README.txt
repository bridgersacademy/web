BRIDGERS ACADEMY WEBSITE — FOUR-PAGE HTML STARTER

Files:
- index.html      Home
- about.html      About Us
- resources.html  Books & Resources
- impact.html     Our Impact

All pages include their own internal CSS and JavaScript, share a consistent design system,
use responsive layouts, and link to one another using relative paths.

Before publishing:
1. Replace the BA monogram with the official logo or logo image.
2. Replace book-cover mockups with official cover image files.
3. Replace # placeholders with official book marketplace links, YouTube links, training flyer,
   event registration links, and the official email address.
4. Add the approved founder biography, formal mission/vision, book descriptions, and real
   testimonials with permission.
5. Replace impact metric dashes with verified numbers or remove the counters.
6. Review the safeguarding, privacy, and consent processes before publishing photographs of minors.

To preview locally, extract the ZIP and open index.html in a browser.
For deployment, upload all four HTML files together to the same folder on your web host.
